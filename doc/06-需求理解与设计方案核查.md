## 6. 结论与后续建议

1. **需求主线已闭环**：R1~R8 / P1~P3 / O1~O4 在 03/04 均有落位，无需推倒重来。
2. **必须补的只有 3 点**：R6 的策略组合层、R6 的目标指标驱动闭环、R1 看板实时通道 —— 三者是需求原文写了、设计未显式建模的“硬缺口”，对应 EX1/EX2/EX3，应作为下一版设计修订（建议并入 03/04，作为 M2/M3 正式范围）。
3. **其余扩充（EX4~EX11）**按里程碑弹性排入，优先 EX9（M1 收尾）以兑现 05 手册。
4. **文档同步事项**：README/各占位 docstring 状态刷新；03/04 API 路径复数→单数对齐（D1）；doc/04 §27 M0 清单勾选复核。
5. 建议在修订设计时新增一节“EX 扩充需求追踪表”，把本文件 §4 的条目编号纳入 DoD，避免后续开发再次漏项。
